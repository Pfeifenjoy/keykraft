# @keykraft/schema

![CI](https://github.com/Pfeifenjoy/keykraft/actions/workflows/ci.yml/badge.svg)

Table and entity definition primitives for [KeyKraft](https://github.com/Pfeifenjoy/keykraft) — a TypeScript-first DynamoDB library built around single-table design.

## Installation

```sh
npm install @keykraft/schema
```

## Overview

This package provides the core schema primitives for defining DynamoDB tables and entities. Your schema is the single source of truth — it drives the query client, the CDK construct, and your TypeScript types.

See the [main repository](https://github.com/Pfeifenjoy/keykraft) for full documentation.
